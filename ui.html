    使用提示
    
  

  

    
启动与关闭

    
先「启动 ComfyUI」等黑窗口出网址 → 再开出图台。出图过程中别关任何一个窗口。
    改过 panel.py / ui.html 后要重启黑窗口；只停出图台的 python 进程，别碰 ComfyUI 的 main.py。

    
底模怎么选

    
默认 Juggernaut 质量最好；一次会话尽量固定一个底模跑完再换——16G 内存下频繁换底模会把模型挤进页面文件，实测卡过 8 分钟。Turbo 只用来抢方向，定稿回 Juggernaut。

    
档位与重绘

    
先用「试方案」判构图（8 步，快），满意后换「评审 / 定稿」出成品——同尺寸同种子，构图一致。
    8 步只够判体块和构图，不能判材质光影（实测铺装粗糙、灌木边缘发花）。

    每条链的重绘默认值都是实测标定的，不确定别动；白模转写实超 0.85 会改结构（加栏杆、改格栅）。

    
底图规范

    
效果图类：要「有体积、有明暗」的截图；平面/彩平类：正投影、关阴影的线稿；带尺寸标注的施工图两类都不要。
    SU 导出务必关阴影——阴影会被当成内容渲成黑块（叁十三平面、轴测白模都实测踩过）。

    
概念底稿路线（11-14 实测）

    
「概念底稿·线稿+提示词」= 单 Lineart 控制网只锁结构，风格全靠提示词。不填提示词就用内置 12 段式配方：
    画质 → 建筑形状 → 材料 → 视角 → 场景 → 风格 → 天气 → 灯光 → 色彩 → 氛围 → 渲染方式 → 镜头。

    实测 1152×768：31.1 s / 7.15 GB；降到 1024×640 只省 0.15 GB——显存大头是模型常驻，降像素省的是时间不是显存。

    换意向图做方案比选已验证可行（同草图同种子，水彩 / 写实两张质感明显分叉、结构全一致），但第二路再叠 0.4 GB，
    8 GB 卡余量很小，别再叠 LoRA 或第二张控制网。资料里的 ArchForge 查无此项目；Flux.2 Klein 属实但要 16 GB 内存 + 全套 GGUF，本机暂缓。

    
出废图怎么办

    
先换种子再调参数——同一个种子重跑三次没用。局部改图提示词要写「把框里改成什么」。

    废图别攒着：点右上 「🗂 成果库」 勾选后「删除选中」，图片连同 .meta.json / 闸门记录一起清，
    不可恢复，直接腾出硬盘空间。

    
区域重绘 · 编辑台

    
出完图不满意，别换种子整张重跑：结果区点「✏️ 编辑 / 局部重绘」，或顶部进「编辑台」。
    选区工具齐全：画笔 / 橡皮 / 矩形 / 椭圆 / 多边形 / 自由套索，笔刷粗细、软边羽化、反选、清空都能调；
    圈出来的就是标准「白=重画、黑=保留」遮罩，圈外像素被锁死。

    提示词要写「这里变成什么」（肯定式），别写「把这棵树去掉」——后者模型不知道填什么，容易糊一片。
    denoise 0.65 换材质 / 0.8 换物件 / 1.0 彻底换内容；接缝明显往下调，不是往上调。
    一次只改一处，改完点「设为底图继续改」接着改下一处。

    切到「批注」是纯本地操作，不用 ComfyUI、不占显存：文字标注、箭头、方框、椭圆框、直线，
    字体下拉只列本机实测已装的（微软雅黑 / 黑体 / 宋体 / 仿宋 / 楷体 / 等线 / 思源 / 方正 / Arial / Times…），
    字号、颜色、粗细、加粗斜体、文字底色随调；元素可拖动、缩放、按图层排序、Ctrl+Z 撤销，导出合成 PNG。

    
多图排版 · 展板台

    
顶部「🖼 展板台」是独立画布工作台：A0/A1/A2/A3 横竖、16:9、正方形、自定义尺寸，缩放、网格、背景色；
    素材直接从成果库（按三大类分组）或本地拖进来，多张图共用一块画布自由拖移、缩放、旋转、调层级与不透明度。

    十三套版式模板一键起稿：经典主图 / 三栏 / 四宫格 / 双拼 / 极简，
    加竞赛常用的三段叙事、2/3 大图、1/2 均分、C 字环绕、网格杂志、T 字形、
    总平中心、压底大图——分析图多选网格杂志，讲生成逻辑选三段叙事，
    点素材会优先填进空图槽，不必一张张手摆；文字标题、色块、分割线、对齐到画布、图层显隐锁定都有。

    导出 1×/2×/3× 全尺寸 PNG，同时存同名 .layout.json，左侧「已存展板」随时打开接着排。
    成稿落 <项目>\出图\展板\，不进 AI 方案稿，不会被成果库当成 AI 出图统计也不会被误删。

    
成果库 · 分类与具体出处

    
成果库按界面三大类（方案表达 / 图纸类 / 风格与修图）→ 具体出图类别（每条链）分组；
    每张卡标出底图、项目、时间、档位、种子、底模、控制网、显存耗时、闸门状态。

    点「一键归档」把散图移动（不复制）进 <项目>\出图\AI方案稿\01_方案表达\白模 → 效果图\ 这类目录，
    每个类别目录生成 _出处清单.md 逐张记录出处；闸门文件里的绝对路径会自动跟着改，
    「撤销归档」可完整还原。归档只动路径，不动 sha256 和闸门状态词。

    
产物去向

    
自动落 <项目>\出图\AI方案稿\，带 .meta.json 记录全部参数；没选项目就落 _未归档AI出图\日期。
    单张成图约 1–2 MB，写盘对 SSD 是噪声；唯一真伤盘的是显存打满后 WDDM 换页，所以别让显存吃满。
